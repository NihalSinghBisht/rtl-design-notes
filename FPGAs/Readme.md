FPGA - FIELD PROGRAMMABLE GATE ARRAY 
-----
- Is a hardware configurable intergrated circuit, is different from a microcontroller that is generally software configurable
- FPGAs are often used in limited (low) quantity production of custom-made products
- Other applications for FPGAs include the telecommunications, automotive, aerospace, and industrial sectors, which benefit from their flexibility, high signal processing speed, and parallel processing abilities.
