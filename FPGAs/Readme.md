FPGA - FIELD PROGRAMMABLE GATE ARRAY 
-----
- Is a hardware configurable intergrated circuit, is different from a microcontroller that is generally software configurable
- FPGAs are often used in limited (low) quantity production of custom-made products
- Other applications for FPGAs include the telecommunications, automotive, aerospace, and industrial sectors, which benefit from their flexibility, high signal processing speed, and parallel processing abilities.
- FPGAs work in parallel: everything is happening at the same time unlike the CPU which is a serial machine that processes one instruction at a time
  - This way of breaking up logic into sequential steps is known as 'PIPELINING'
  - Much of the delay from the FPGAs are not from the logic itself but is from the connection between the CLBs
  - img ( connection bw CLBs )
  - the only downside is that every switch adds capacitance to wires which slows down how fast signals can pass through them
